# MyKegs.US

Одностраничный лендинг MyKegs USA: ремонт, восстановление и продажа пивных кег.

Статический HTML, CSS и ванильный JS без сборки и зависимостей. Вёрстка перенесена из Claude Design.

## Структура

```
site/                   то, что публикуется на сайте
├── index.html
└── assets/
    ├── styles.css      все стили, токены в :root
    └── app.js          бургер-меню, FAQ, слайдер «до/после», заглушка формы
.github/workflows/      автопубликация site/ на GitHub Pages
```

## Публикация

Каждый push в `main` публикует папку `site/` на GitHub Pages (workflow `pages.yml`).
Остальные файлы репозитория на сайт не попадают.

## Что ещё не готово к запуску

- Телефон, email, адрес, зона обслуживания: заглушки.
- Фото: стоковые с Unsplash; в слайдере половина «до» пустая.
- Отзывы и ответы FAQ: черновики, нужны настоящие.
- Формы никуда не отправляют заявки: на статическом хостинге показывается сообщение «спасибо».
- Страница закрыта от поисковиков (`<meta name="robots" content="noindex">`). Снять перед запуском.
- Юридические страницы и ссылки на соцсети не сделаны.
